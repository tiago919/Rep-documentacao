# Rep-documentacao
App-blog

sistema de blog com área pública e painel administrativo

Tecnologias 
PHP8 
MySQL 
HTML 
CSS 
Funcinalidades

Front-end listar e ler postagens 
Painel admin, login, criar,editar e excluir postagens

Como executar

1.Instale o XAMPP e inicie o Apache e o MySQL 
2. copie a pasta app-blog para hábitos 
3.Importe p arquivo banco/app_blog.sql no phpMyAdmin 
4.acesse http://localhost/app-blog

Acesso ao painel admin(somente para testes)

URL:http://localhost/app-blog/admin 
usúario:admin@test.com 
senha:123456

Estrutura de pastas 
/admin: painel administrativo 
/public:paginas do front-end 
/css:estilo
/includes:conexão com o banco e funções 
/banco:script SQL 
/docs:documentação
